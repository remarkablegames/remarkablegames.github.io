🐹 [ebiten-template](https://github.com/remarkablegames/ebiten-template) is a template for making 2D games with [Ebitengine](https://ebitengine.org/) in Go.

<iframe src="https://remarkablegames.org/ebiten-template/" frameborder="0" width="100%" height="517" style="display: block; margin: 0 auto;"></iframe>

## Features

1. **Hot reload**: on desktop, the game reloads on save so you can edit a file and watch it update.
2. **1 codebase, 3 targets**: native binaries for Windows, macOS, and Linux; WebAssembly for the browser.
3. **Embedded assets**: ships with a working sprite sheet.

## Prerequisites

Install [Go](https://go.dev/doc/install):

```sh
brew install go
```

## Install

Clone the repository:

```sh
git clone https://github.com/remarkablegames/ebiten-template.git
```

Change into the directory:

```sh
cd ebiten-template
```

Run the game:

```sh
go run .
```
