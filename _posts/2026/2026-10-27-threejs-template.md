📐 [threejs-template](https://github.com/remarkablegames/threejs-template) is a template for making 3D web games.

<iframe src="https://remarkablegames.org/threejs-template/" frameborder="0" width="100%" height="600" style="display: block; margin: 0 auto;"></iframe>

## Features

The [template](https://github.com/remarkablegames/threejs-template) sets up a [scene](https://threejs.org/manual/#creating-a-scene) with a spinning cube. It includes:

- **Three.js** boilerplate with TypeScript support.
- **Vite** build optimized for development and production.
- **GitHub Actions** CI that deploys to [GitHub Pages](https://pages.github.com/), builds desktop apps with [tauri-action](https://github.com/remarkablemark/tauri-action), and uploads the game to [itch.io](https://itch.io/) and [Wavedash](https://wavedash.com/).

Check out the source code on [GitHub](https://github.com/remarkablegames/threejs-template) or view the [demo](https://remarkablegames.org/threejs-template/).
